# 金脆坊 線上訂單 × Google Sheet 串接說明

網站結帳 → Google Apps Script（GAS）→ 寫入 Google 試算表，並自動寄信給顧客與店家。

```
顧客按「送出訂單」
   │  POST JSON（品項 ID、數量、顧客資料）
   ▼
GAS doPost ── 驗證資料 ── 依「菜單」工作表重新計價 ── 產生訂單編號（JCF261127-001）
   │                                         │
   ├─ 寫入「訂單」「訂單明細」工作表             └─ 寄確認信給顧客、新訂單通知給店家
   ▼
回傳 { ok, orderId, total } → 網站顯示訂單完成畫面
```

## 一、建立試算表與程式（約 5 分鐘）

1. 到 Google 雲端硬碟新增一份 **Google 試算表**，命名例如「金脆坊訂單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡預設的 `Code.gs` 內容全部刪掉，貼上本資料夾的 [`Code.gs`](Code.gs) 全部內容，按 💾 儲存。
4. （選填）修改檔案最上方的 `CONFIG`：
   - `SHOP_EMAIL`：要收新訂單通知的信箱，留空就寄到試算表擁有者的 Gmail。
   - `SHIPPING_FEE` / `FREE_SHIP`：運費與免運門檻（要和網站上的設定一致）。
5. 函式選單選 **`setup`** → 按 **▶ 執行**。第一次會要求授權：
   選擇你的帳號 → 「進階」→「前往（不安全）」→「允許」。
   （這是你自己的程式，Google 對未經審核的個人程式都會這樣提示。）
6. 回到試算表，會看到三個工作表：**訂單、訂單明細、菜單**，上方多一個「金脆坊」選單。

## 二、部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 類型選 **網頁應用程式**，設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（顧客不需要登入 Google 才能下單）
3. 按「部署」，複製 **網頁應用程式網址**（`https://script.google.com/macros/s/……/exec`）。
4. 打開網站的 `index.html`，找到：
   ```js
   const ORDER_API = '';
   ```
   把網址貼進引號中，存檔並推送到 GitHub。
5. 在網站下一筆測試訂單，確認試算表有出現資料、信箱有收到信。

> ⚠️ 之後修改 `Code.gs`，要用 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**，網址才會維持不變。
> 若直接「新增部署作業」會產生新網址，網站就得跟著改。

## 三、日常使用

| 工作表 | 用途 |
| --- | --- |
| **訂單** | 一筆訂單一列。「狀態」欄可下拉選擇：新訂單 / 製作中 / 可取餐 / 已出貨 / 已完成 / 已取消，會自動上色。 |
| **訂單明細** | 一個品項一列，方便用樞紐分析統計各品項銷量。 |
| **菜單** | 後端計價依據。可改價格、取消勾選「上架」來停售。**網站上的價格也要同步修改**，否則顧客看到的金額會和實收不同（以試算表為準）。 |

- 把狀態改成 **可取餐** 或 **已出貨** 時，系統會自動寄信通知顧客，並記錄在「通知紀錄」欄，同一狀態不會重複寄。
- 選單 **金脆坊 → 今日營收統計**：顯示今天的有效訂單數與營業額。
- 訂單查詢 API：`<網址>?action=status&id=訂單編號&phone=手機`（需手機號碼相符才會回傳）。

## 四、安全設計

- **價格以伺服器為準**：網站送來的價格與總額只做參考，GAS 一律用「菜單」工作表重新計算，避免被竄改金額。
- **資料驗證**：手機、Email、取餐方式、宅配地址、品項與數量（1–99）都會檢查。
- **防公式注入**：顧客輸入以 `=`、`+`、`-`、`@` 開頭的文字會被當成純文字存入。
- **防機器人**：表單有隱藏的陷阱欄位，被填寫的請求會被忽略。
- **訂單編號不重複**：以 LockService 鎖定，同時多筆下單也不會撞號，每日從 001 重新編號。

## 五、限制與注意

- Gmail 個人帳號每日寄信上限約 **100 封**（Google Workspace 約 1,500 封），訂單量大時請留意。
- Apps Script 回應約需 1–3 秒，網站送出時會顯示「送出中…」。
- `ORDER_API` 留空時，網站為**示範模式**：可以走完結帳流程，但訂單不會送出，完成畫面會標示「示範模式」。
